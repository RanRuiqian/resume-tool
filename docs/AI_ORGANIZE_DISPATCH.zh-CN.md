# AI 整理现有资料：调用路径与事实保护修复

本轮继续更新 Draft PR #16，基分支/依赖链不变，不合并、不部署。没有调用真实 DeepSeek、读取用户 Key 或操作用户当前浏览器资料。自动化使用虚构资料和模拟 HTTP；真实 V7 仅用于本地只读复现，正文不进 Git/CI。

## 根因与复现证据

实际按钮调用链是 `OrganizePanel.run(true)` → `planOrganize(..., {useAi:true})` → `modeOf` 选材 → `chatJson` → `chat` → 当前配置的 `/chat/completions`。

原逻辑有两道发送前筛选：

1. 所有已有语言都被 `confirmedLang` 判为确认时直接跳过。V7 的 `[x]` 会正确建立字段确认状态或 userConfirmedAt，导致已审核的经历正文整体被排除。
2. 剩下的文字只在本地检测到说明句、第一人称、格式问题，或需补译时才发送；“干净”文字不会请 AI 审阅。

因此即使 useAi=true，也可能 todo 为空，完全不进入 chatJson/fetch。界面的 3 条本地建议与 103 条保持原文是本地结果，不能证明 DeepSeek 连接或 Key 有问题。

使用同一真实 V7 原件组装已审核资料，在纯内存、模拟接口下复现：共106条文字（不含名称字段），其中105条简介/经历/项目正文进入6批请求；1条求职意向不参与。另有53个名称字段不计入正文统计且不参与优化。模拟接口逐字返回原文时，仍是103条保持原文、3条本地建议，但现在**明确记录6次请求和105条AI返回结果**。不要求模型为了展示成果强行改字。

## 修改

- 用户明确选择 AI 时，已确认事实对应的简介、工作及项目要点可以送审；不再把“事实已确认”误解为“禁止审阅措辞”。实际改动仍需用户选择/写入，已确认文字的 AI 建议默认不勾选。
- 名称、求职意向、教育和课程等结构事实不进入措辞优化；日期/学历等源文复核修改仍属于单独的本地复核，AI 操作不生成此类字段修改。
- 数字、日期、学位状态、单位/工具、参与程度、合作/否定/仿真/临床边界的原有事实检查保留。失败反馈重试一次；仍不完整则拒绝并保留原文。项目 archive 只接受原句，不能绕过正文检查注入新事实。模型返回额外日期、来源ID等字段不会应用。
- 通过原有事实检查的格式和英文语法建议可进入人工审核，不把“只改格式”当作从未请求过AI。保留对无价值删字的限制，不无条件采纳语义改写。
- 同模型、规则与原文指纹可复用；规则盐升级，旧的筛选结果不会阻止这轮首次审阅。复用时明确说明未发送原因，提供“重新调用 AI 审阅”；强制重审仍不能改受保护字段。
- 空资料、整条内部说明、仅有受保护内容、演示模式、仅本地操作，都明确显示不调用原因。鉴权/余额/模型配置失败后停止其余批次，避免重复无效调用。
- 请求观测绑定到单次 chat/chatJson，记录实际 fetch 尝试（含 JSON 重试）、请求模型及服务返回的模型，不混入并行的连接测试。服务不返回 model 时显示“无法核实响应模型”，不拿请求配置冒充响应。
- 完整成功、部分失败、全批失败、缺少结果、非字符串/缺少正文、空返回、JSON 格式错误、超时等分别显示。全批失败保留错误状态，不用本地结果冒充 AI 成功；部分失败条目保留原文，本地建议单独标注。
- 写入前检查资料是否在审阅期间变化，阻止旧计划覆盖当前资料。所有操作继续经过快照与既有清空代次保护。

## 界面

结果区“请求模型”与“响应模型”分开显示；展示实际请求尝试次数、成功/部分完成/失败批次、AI 返回审阅条数。AI 返回条数与建议修改条数分开统计，本地和 AI 建议都有明确来源。

“未发送原因”包含受保护字段、内部说明或同模型已审阅等原因。统计为不同维度：被拒绝的 AI 建议可能同时对应原文保留或本地建议，界面明确提示数量不能相加，避免把审阅数、修改数和拒绝数混为一谈。

## 人工验收

1. 在 PR #16 最新代码的测试浏览器中，确认当前启用 API 与模型、演示模式关闭；点击“AI 整理现有资料” → “调用 AI 规范化措辞”。
2. 应看到逐批进度，结束后检查请求次数、请求/响应模型、成功或失败原因；返回原文的条目也计入 AI 审阅，而不是“未调用”。
3. AI 若提出措辞建议，已确认文字默认不勾选；选择并确认写入前，个人资料不得改变。核对学历、日期、成绩、项目事实、来源编号与原件一致。
4. 如全部已由同模型审阅且原文未变，应明确说明复用原因，可点“重新调用 AI 审阅”；若只剩受保护字段，应解释为何不发送。
5. 服务异常应显示具体原因和实际尝试次数，不能显示本地结果为AI成功。需要验证错误时使用隔离测试/模拟响应，不在真实资料上做破坏性实验。
