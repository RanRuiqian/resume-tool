# 「AI 整理现有资料」使用说明

## 它做什么
资料母库是你的**完整事实记录**。整理只做三件事：去掉不适合求职的说明 / 提醒句（移到备注，不删除）、去掉「我」主语和格式问题、补齐缺失或过期的英文。它**不会**缩短内容、不会删掉真实成果、不会降低信息密度——按岗位精简是在「生成简历」时才做的。

**事实一律保留**：地点、合作对象、参与程度、团队规模、限定条件（约 / 估算 / 不代表 / 非官方 / 仅室温 / 尚未）、完成状态（讨论过 ≠ 已实现）、并列成果（照片、视频、Demo、GitHub、报告等一项都不能少）、经历性质（课程 / 实习 / 全职）。限定句本身就是事实，不会被当作说明移走。失败方案和局限会复制一份到项目档案，原要点保留。

## 哪些内容会发给 AI
只发送真的有问题的条目：含说明 / 免责句、第一人称、格式问题，或英文缺失 / 过期。已经干净的条目不发送、不改动，算作「无需修改」。AI 被要求「能不改就不改」；只删了「曾」「了」之类字词的改写会被直接忽略。

## 整理报告的五个数字
- **清理的不适合求职说明**：说明句已移到备注。
- **实际改善表达**：去主语、修格式、补译（英文已和中文交叉核对）。
- **无需修改**：本来就干净，原样保留。
- **AI 建议因事实不完整被拒绝**：AI 的版本丢了或改了事实。系统已把丢失的具体内容反馈给 AI 重试一次，仍不完整就保持原文（只做本地安全清洗）。可展开查看原因，无需处理。
- **需要你审核**：AI 改了措辞，没发现丢事实，但无法证明完全等价。默认不写入——**这不是成功修改**，有空再看即可。

## 推荐步骤
1. 「我的资料」→「AI 整理现有资料」。系统会先自动保存快照。
2. 看整理报告，直接点「全部接受」→「写入」（只写入能证明安全的修改）。
3. 有空时再看「需要你审核」，觉得 AI 版本更好、且事实没变的，单独勾选。
4. 不满意随时「恢复快照」。
5. 以后规则或模型更新，点「重新检查已拒绝建议」，不用重新导入。

## 资料状态
页面上分三项显示：
- 🧹 内容清洗：还有多少说明句 / 「我」主语。
- 🔎 事实核对：导入时标出的待核实事实。
- 🌐 英文翻译：机翻条数（可直接用于求职，生成时会再核对），以及「待更新」条数。中文改过、英文没跟着改的，会标「待更新（原文已改）」，生成简历时不会静默使用过期英文。

## 注意
- 事实检查靠规则和词表，偏保守：少数合理的改写也可能被拒绝（原文保留，不会出错），词表外的同义错误仍可能漏掉。正式投递前仍建议读一遍。
- 译文与中文不一致时标「译文待核对」并拒绝写入，原英文保持不变；同一条中文的安全清洗照常写入。
