# 「AI 整理现有资料」使用说明

## 它做什么
把已导入的资料母库整理干净：去掉「我」主语、把「实际职责以本人能核对的操作范围为准」这类说明 / 提醒移到备注、把失败方案归档到项目档案，并补齐英文。**事实一律保留**：地点、合作对象、参与程度、团队规模、限定条件、完成状态、并列职责、因果结论、经历性质（课程 / 实习 / 全职）。

## 两类修改
- **A 类 · 机械清洗**（默认已勾选，可一键批量接受）：只做去主语、移出说明句等本地规则能证明安全的修改。
- **B 类 · 需要你判断**（默认不勾选）：AI 改了措辞，且无法证明与原文事实完全等价。每条会显示可能丢失的内容，例如「改写后找不到原文片段：『在公司』」「参与程度变化：协助 → 负责」。同一条文字会在 A 类里同时提供一个只做机械清洗、保留全部事实的版本，所以不需要逐条重写。

## 推荐步骤
1. 「我的资料」→「AI 整理现有资料」。系统会先自动保存快照。
2. 查看整理报告，直接点「接受全部安全修正」→「写入」。
3. 有空时再看 B 类，觉得 AI 版本更好、且事实没变的，单独勾选。
4. 不满意随时「恢复快照」。
5. 以后规则或模型更新，或想再看一次之前拒绝的建议，点「重新检查已拒绝建议」，不用重新导入。

## 资料状态
页面上分三项显示：
- 🧹 内容清洗：还有多少说明句 / 「我」主语。
- 🔎 事实核对：导入时标出的待核实事实。
- 🌐 英文翻译：机翻条数（可直接用于求职，生成时会再核对），以及「待更新」条数。中文改过、英文没跟着改的，会标「待更新（原文已改）」，生成简历时不会静默使用过期英文，而是标为需核对。

## 注意
- 规则检查偏保守：可能把没问题的改写放进 B 类，但不会把丢失事实的改写默认写入。
- 英文重新机翻只做数字核对，正式投递前建议读一遍英文版。
