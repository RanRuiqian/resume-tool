# 数据与密钥安全边界（个人版）

本工具是纯前端应用，没有自己的服务器。

## API Key
- 保存在本浏览器的 IndexedDB（`settings` 表），只在调用 AI 时放进请求头 `Authorization` 直接发往你配置的服务商（默认 DeepSeek）。**不会**放进网址参数（Base URL 带参数会被拒绝保存）。
- 可保存多套配置（「设置 → AI API 管理」）。界面只显示脱敏 Key（如 `sk-••••••1234`）；编辑时 Key 输入框为空，留空即保留原 Key。删除配置会同时删除其 Key；删除当前配置不会自动换用其他 Key。
- 升级到多配置时，会在同表保存迁移记录 `settings-premigrate-profiles-v1`，**只含服务商 / 地址 / 模型 / Key 末 4 位脱敏 / 时间，不含明文 Key**。每次加载会清理 `settings` 表中主记录以外任何行的明文 Key（兼容旧版本写入的快照）。
- API 地址只允许 `https://`；`http://` 仅限本机 `localhost` / `127.0.0.1` / `[::1]`（本地开发代理）。保存时校验，发送请求前再检查一次，旧的不安全配置不会发出带 Key 的请求。
- 连接测试只发一次最小请求，错误信息中如果服务商回显了 Key 会被替换为 `***`。
- **这不是服务器级的密钥保护**：Key 以明文保存在浏览器本地数据库中，没有加密，也不会在设备 / 浏览器之间同步（换电脑、换浏览器、清除网站数据后需重新添加）。
- 不写入 JSON 备份、历史快照、导出 ZIP，不打印到控制台。
- **边界**：任何能在本机打开这个浏览器配置文件、或在同一页面注入脚本（例如恶意浏览器扩展）的人都能读到 Key。请勿在公用电脑保存 Key；建议在服务商后台给 Key 设置额度上限，泄露后立即作废。公开发布多用户版本时应改为服务端代理，不能沿用此方式。
- 仓库与 CI 不含任何真实 Key：`npm run e2e:ai` 只从环境变量 `DEEPSEEK_API_KEY` 读取；GitHub Actions 的 PR 检查不配置任何密钥，只跑离线测试。

## 发送给外部 AI 的内容
| 操作 | 会发送 | 不会发送 |
|---|---|---|
| 智能导入 | 你粘贴 / 从文件提取的那段文字（里面写了什么就发送什么，包括其中写的本地路径） | 照片、证据文件本身 |
| 生成简历 / 本地化 | 岗位要点；已启用条目的公司、职位、时间、要点、标签；教育；技能 / 证书 / 获奖名称；简介；术语表 | 姓名、联系方式、照片、出生年月 / 性别 / 籍贯 / 政治面貌、项目详细档案、证据文件及其本地路径 |
| 补全翻译 | 待翻译的字段文字 | 同上 |
| 事实审查（第二阶段） | 不调用 AI，全部本地规则 | — |

界面在调用前会显示上述说明（`AiDisclosure`、智能导入按钮下方提示）。测试 `tests/aiPayloadA4.test.ts` 会检查生成请求中不含证据、本地路径、联系方式与项目档案。

## 本地数据
- 真实资料库（`resume-tool`）与演示资料库（`resume-tool-demo`）是两个独立数据库，演示模式不会读写真实资料。
- 每次导入 / 替换 / 撤销前自动保存历史快照；可随时导出 JSON 备份。
- 数据库升级只做增量迁移（Dexie version），不会清空已有数据。
