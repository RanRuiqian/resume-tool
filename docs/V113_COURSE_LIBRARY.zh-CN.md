## 本批已实现

- 独立课程库，和项目分开管理：本科/硕士折叠分组、紧凑列表、单条展开、搜索别名/学期/知识标签，手动新增/编辑/停用、删除确认与快照、最近删除撤销。官方双语名允许缺一项；不造译名。概述与证据等级分开，推断、回忆、官方和待核实状态可见，不写进简历正文。
- 稳定课程 ID、学校/教育关联、学期、代码、原始学分/成绩及待公布/遮挡状态、来源和人工确认；两个项目学分单元可指向同一个现有项目，计数和打印均不视作额外授课课程，也不创建项目。旧教育 courses/旧课程项目原样保留，不擅自搬动真实资料。
- 专用 TXT/JSON 草稿导入：先预览差异，默认跳过；用户明确选新增、仅补缺或替换，且先事务备份。相同代码/身份的互补双语合并，无共同身份的疑似异语课程阻止自动新增，冲突不会静默覆盖。新导入一律待审核。通用格式已测 76 本科 + 6 硕士 + 2 项目学分；未提供的人类 V5 文本没有假装已适配。
- 仅在本份简历选择确认过的授课课程，并可排序；正文打印官方课程名与「课程知识」标签，不打印概述。学术成绩默认隐藏，逐课主动开启才打印原始成绩，中英 HTML/PDF/DOCX 共用一个排版模型。不换算 GPA，未公布/遮挡待核实成绩不可公开。新简历课程快照及新申请快照不保存隐藏成绩；明确开启的成绩随该简历冻结。母库/私有备份仍完整保留成绩。
- Dexie v5 增量升级：升级事务内先备份原始 v4 资料，再追加空 courses，其他表原样保留；写入失败事务整体回滚。升级前备份不被最近 20 份轮替删除。资料替换/合并的备份与写入也改为同一事务，保存成功后才更新界面；失败不显示候选已保存。启动失败显示保留数据/重试指引，不清库。
- 保存过的简介不再因 machine/stale 状态整栏消失；原样保留、标待确认，只有真实 confirmed 才称已确认。缺语言仍不自动编造。人工岗位变体需明确应用，只影响本份简历，保留固定版、撤销和事实审查；未接入额外的 AI 变体调用。
- GitHub、LinkedIn、网站、作品集各自启停，默认隐藏，新简历保存开关；不把链接当工程项目证据。保留正式专业名和原始语言证据，不变成不同专业、流利英语或换算 IELTS。
- 未确认 AI 导入的工作/项目/技能/奖项留在母库，但不自动进入可靠选材白名单。重新解析 JD 保留手工简历与选择，不自动重生成；用户明确点击后才创建新版本。重复工作 ID 不重复渲染，校园经历按现有分类单列。
- 关键词界面改为「内部辅助分析」，缺词提示为本简历尚未证实；不冒充官方 ATS 或录用概率。既有事实 ID、所属经历、局部修复、实体、限定、数字、双语检查全部保留，没有降低事实安全门槛。

## Codespaces 预览与最短验收（7 步）

```bash
git fetch origin
git switch feat/v1.13-course-library
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

端口面板打开 5173；首次验收优先用独立浏览器资料或 `?demo`，不要把虚构测试库覆盖真实库。不用填真实 Key 即可查看课程管理与已有简历。

1. 先导出自己的私有资料备份，确认历史简历、设置、投递记录仍在；升级前快照可见。
2. 我的资料→课程：本科/硕士分组、单条展开、名称/别名/知识方向搜索；缺英文名不编造。
3. 用导出格式的少量虚构 TXT/JSON 草稿预览差异，确认默认跳过、补缺不覆盖人工内容，删除可撤销。
4. 核对固定简介双语原文；待确认文字仍显示，手动确认后再投递。尝试本份简历变体及恢复，确认母库不变。
5. 生成/预览→本份简历选项：选课程，成绩默认关闭，逐课显式开启；核对 GitHub/网站/作品集独立开关。
6. 检查中英 PDF/Word 的专业、经历性质、日期、语言证据、工作/校园分类、成绩和字体；在 Word 中核对实际分页。
7. 修改/重新解析 JD，确认手动简历保留且不会自动调用模型；点击明确重新生成才创建新版。审阅全部高风险项，未确认前不用于投递。
