# PR #16：AI 辅助简历工具的产品简化与验收

产品定位：建立可复用个人资料库，结合岗位要求用 AI 生成真实、专业的简历，再自由编辑和导出。不是事实认证、科研审查或企业合规系统。

## 本轮变更

- 向导从四页收为三页：个人资料 → 岗位要求 → 编辑与下载。旧 `wizardStep=4` 自动打开第三页，不要求重新导入。
- 保留现有 AI 岗位理解、语义选材、排序、写作与本地化，真实模式不以关键词流程代替 AI。AI 输出继续校验来源 ID、数字/日期、学位状态、工具、参与程度等；错误仍须修复或拒绝。
- 保留现有素材池和模板渲染，两个生成入口共用左右选择/预览体验。勾选仅更新本简历，不自动翻译或调用 AI。
- 取消项保存最新 AI/人工双语文案、要点子集和顺序；刷新仍保留，重新勾选恢复。AI 合并的多个事实作为一个句子整体选择，避免取消后偷偷恢复原文或保留未选事实。
- 左侧可直接编辑本简历文字、标题、学位表述、日期和技能名称。标题字段在渲染时叠加到临时副本；不修改母库或来源 ID。用户清空文字后不再被原文重新填回；自动成绩仍默认隐藏，用户明确单独选择/手改的文字正常显示。条目顺序可直接调整。
- 翻译只由「同步翻译」按钮显式触发。单语素材先展示已有原文并标为可选同步；按实际已有语言补齐，不发送空白、不多翻译一轮。用户主动清空的文字保留；不合格 AI 译文重试后仍失败则保留现有文字，不写入虚构数字。请求期间若简历已修改，旧响应不覆盖当前编辑。
- 移除事实审查面板、风险二次确认、证明材料/证据位置/学位证明状态录入和认证待办中心；取消匹配评分和关键词命中面板。岗位匹配说明折叠、可选查看，多岗位功能继续保留。
- 人工文字可编辑、预览和导出；关键差异只作简短提示。求职信/自我介绍不再因人工修改被排除导出，关联共同简历版本也不再要求审查通过。默认简历 ZIP 不附加审查 JSON。
- 导入仍先预览，真正的条目冲突仍需选择处理方式；选择新值/替换后不再要求另一个风险复核。整库替换、删除及「清空所有个人资料」保留正常的数据删除确认。

## 数据兼容

数据库仍为版本 6，不增加迁移，不删除字段、表或旧记录。新增内容都是 ResumeDoc 可选字段：取消项缓存、选择/顺序记忆、当前简历字段编辑，已经包含在原有完整备份 section 中。旧 evidence/audit/kitReview 元数据继续保存兼容，界面不再要求用户完成它们。

V7 来源账本、课程、原始成绩及翻译、API 设置、模板、投递及历史快照保留。一键清空的定向清理、epoch 防旧数据回写及不可变投递版本保护保留。没有修改用户原始母库或当前真实浏览器资料。

- 单元/集成测试：41 文件，627 项通过。覆盖新编辑/缓存/顺序/备份/旧记录兼容；原 AI 不存在 ID、错误引用、局部修复、事实捏造拒绝等回归继续通过。
- 类型检查、Lint、生产构建通过。构建保留现有动态/静态混合导入提示，不影响产物；不为此扩展重构。
- 三个原有模板的中英文 PDF/Word 导出通过。新浏览器测试实际解压下载 ZIP，并抽取中英文 PDF 和 Word 内容，验证当前人工文字与取消项。
- 新编辑浏览器回归 25/25：勾选/编辑/排序零 AI 请求、刷新恢复、标题编辑、两个生成入口、移动端、自由导出、API/资料/投递不变。
- 收尾复核修正了投递脚本对旧「事实审查」文案的断言，改查快照真实内容与无审查门槛，并补上失败退出码；单独重跑 33/33 通过。其余最终通过记录复用，未重跑无关全量测试。
- 浏览器总计 335 项：素材编辑25、智能导入41、AI整理36、API配置48、投递33、发布/备份35、课程18、联合岗位18、清空17、原编号格式14、AI调用路径16、信息丢失20、真实V7导入14。
- 真实 V7 只读隔离验证 353 项，浏览器隔离导入 14/14：299/299 来源事实，本科 76/76、硕士 6/6、核心项目 2/2；重复导入不增记录，刷新保持完整，当前预览 0 内部重复/0 强制核对。历史 15/80 原 AI 清单未提供，不能复原逐项清单；以上是当前真实原件的实测。
- 浏览器使用临时独立数据目录并阻断外网，AI HTTP 均模拟；没有读取用户真实 API Key 或调用真实 DeepSeek。真实 V7 不提交 Git/CI、不截图、不录制 trace，文件校验保持不变。

## 人工验收

1. 在包含 PR #13 → #14 → #15 → #16 的分支启动本地预览，使用已有 V7 资料，无需重导。
2. 关闭演示模式并启用自己的 AI 配置，粘贴 JD 或上传截图，生成简历。确认 AI 完成选材/撰写后进入「编辑与下载」。
3. 在左侧修改一条中文/英文正文，再取消整段经历：右侧立即消失；刷新后仍取消。重新勾选，人工文字恢复。对单条要点、简介重复操作。
4. 勾选另一条素材，调整上下顺序和模板；右侧立即更新。浏览器网络面板中这些操作不应新增 `/chat/completions` 请求。
5. 展开「编辑本简历标题与日期」，修改本简历标题或日期，检查预览同步；回到「我的资料」，母库应保持原样。
6. 下载中英文 PDF/Word，检查选中内容、人工文字、顺序和模板一致，取消项不出现。普通文本差异提示不应要求上传证明或阻止下载。
7. 如需另一语言优化，明确点击「同步翻译」；可以继续编辑。迟到的翻译结果不应覆盖期间新编辑。
8. 检查课程仍完整、API 连接可用、投递历史和共同简历版本可打开。不要用真实资料执行清空测试；清空功能已有虚构数据回归。

浏览器复现新增测试：先启动构建后的 Vite preview，再运行：

```bash
npx tsx --tsconfig tsconfig.app.json scripts/prepare-workspace-e2e.ts
python3 tests/e2e/resume_workspace_e2e.py
```

需要本机安装 Playwright、Chromium 和 PyMuPDF；`CHROMIUM_PATH` 可指定浏览器路径。新测试只建立虚构资料和临时浏览器目录。
